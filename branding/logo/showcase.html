05

设计说明 & 资产下载

概念。硬直角机箱 = 裸金属机架;内部镂空形成 1 条全宽机架导轨 + 2 个驱动仓;熔接的锁孔承载 LUKS 全盘加密叙事——字面意义的 "Rack Lock"。

技术。单一 <path>,fill="currentColor" + fill-rule="evenodd"。所有内部细节都是真镂空(在非白底验证透明),不依赖背景色变量,Chrome 与 rsvg-convert 渲染一致。

为什么用实心而非描边。实心填充在缩小时远比细平行描边稳。直角(rx=6)刻意保留——大圆角会被读成盾牌 / 记事本,硬角才说"金属盒子"。

favicon 变体。同机箱,精简为 1 条粗导轨 + 1 个加大锁孔(无分仓),≤24px 不糊。两者同构,是一个家族。

用法。≥32px(侧栏 / 登录 / 文档)用主标;≤24px(favicon / 应用图标)用 favicon 变体。颜色用 CSS color: 控制。
